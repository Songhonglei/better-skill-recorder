手动安装

下载、校验，再拖入应用程序

  1. 下载并校验

    下载 ZIP 和 SHA256SUMS.txt，放在同一文件夹，在该目录执行以下命令，确认显示 OK

    shasum -a 256 -c SHA256SUMS.txt下载校验文件 ↗

  2. 移入应用程序

    解压后将 App 拖入「应用程序」。当前预览版如被 macOS 拦截，请按安装指南手动放行，不要关闭系统整体安全保护

  3. 授权与连接模型

    允许录屏后重启 App；旁白需要麦克风权限。在模型管理填写模型 ID、BaseURL 和 API 密钥，测试连接后保存

还有几个你可能关心的问题

需要额外订阅吗？

App 开源免费，不要求 GitHub Copilot 订阅。分析和生成需要你自己的 OpenAI 兼容模型，调用费用由服务商收取。模型需支持工具调用，视觉分析还需支持图片输入

录制内容会发到哪里？

分析和生成时，相关内容会发送至你配置的模型服务。安全录制会尝试本地脱敏，但可能漏检或误遮挡。关闭视觉分析仅阻止图片发送，分析文本仍会发送；分享前请人工检查

安装和使用有哪些限制？

当前预览版未经过 Apple 公证，安装需要手动放行，升级可能需要重新授权。没有自动更新，不录制系统音频；旁白首次使用可能下载本地转写模型。定时 Skill 需由支持该能力的智能体导入运行，App 不托管定时任务

如何反馈问题？

请提供 App 版本、macOS 版本、芯片和复现步骤。截图与日志先脱敏，不要上传密钥、个人配置或私密录制
