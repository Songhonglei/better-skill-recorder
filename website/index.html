  1. 下载并校验

    在 Release 下载 ZIP 和 SHA256SUMS.txt，放入同一文件夹，在该目录执行以下命令，确认显示 OK

    shasum -a 256 -c SHA256SUMS.txt下载校验文件 ↗

  2. 拖入「应用程序」

    解压后移动 App，再打开。如果 macOS 拦截，仅在确认来源可信后，前往「系统设置 → 隐私与安全性」选择「仍要打开」

    Apple 官方放行说明 ↗

    不要关闭系统整体安全保护；受管理电脑请联系管理员

  3. 授权并连接模型

    授予录屏权限后重启 App，旁白需麦克风权限。在「模型管理」填写模型 ID、BaseURL、API 密钥，测试连接后保存

    模型需支持工具调用，视觉分析还需图片输入能力，调用费用由你配置的服务商收取

  4. 先试一个小任务

    录制 20–30 秒不含敏感信息的操作，结束后进入录制记录分析并生成 Skill。分享前，请人工检查结果

开始前，你可能想知道

需要 GitHub Copilot 订阅吗？

不需要，分析和生成使用你自己的 OpenAI 兼容模型。普通用户也不需要安装开发工具。服务商模型费用另计

数据会发送到哪里？

分析和生成时会发送相关内容到你配置的模型服务。安全录制开启时会先尝试本地脱敏；关闭视觉分析可阻止图片发送，但分析文本仍会发送。旁白首次使用可能下载本地转写模型

升级、权限与定时任务有什么限制？

目前没有自动更新，下载新版后退出 App 再替换。未公证版本升级可能需要重新授权。定时 Skill 是导出的文件包，需要支持定时或触发能力的智能体运行，App 本身不托管定时任务。不录制系统音频

如何反馈问题？

请提供 App 版本、macOS 版本、芯片、复现步骤和脱敏截图，不要上传密钥或私人录制
