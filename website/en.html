GET STARTED

Two ways to get started

Apple Silicon Macs are supported today; Intel Mac / Windows / Linux installers are not yet supported

Manual installation

Download, verify, move to Applications

  1. Download and verify

    Download the ZIP and SHA256SUMS.txt to the same folder. Run this command from that folder and confirm it reports OK

    shasum -a 256 -c SHA256SUMS.txtDownload checksums ↗

  2. Move to Applications

    Unzip and move the app into Applications. If macOS blocks this preview, follow the installation guide to allow it manually—do not disable system-wide protection

  3. Grant access and connect a model

    Allow screen recording and restart the app. Narration needs microphone access. Enter a model ID, BaseURL and API key in Model management, test the connection, then save

A few things worth knowing

Do I need a subscription?

The app is free and open source. No GitHub Copilot subscription is required. Bring your own OpenAI-compatible model and pay its provider for usage. Tool calling is required; visual analysis also needs image input support

Where does my recording go?

Analysis and generation send relevant content to your configured model service. Safe recording attempts local redaction, but can miss or incorrectly mask information. Turning off visual analysis prevents image uploads, not analysis text. Review content before sharing

What are the current limitations?

This preview is not notarized by Apple and needs manual approval; updates may need new permissions. There is no auto-updater or system-audio recording. First-time narration may download a local transcription model. Scheduled Skills need a capable host agent; the app does not run scheduled jobs

How do I report a problem?

Include the app version, macOS version, chip and reproduction steps. Redact screenshots and logs first. Never upload API keys, personal configuration or private recordings
