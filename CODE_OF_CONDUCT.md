# Code of Conduct

## Our standards

We are committed to a respectful, harassment-free community. Be constructive, assume good
intent, respect privacy, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, publishing
credentials or private recordings, sexualized content, and sustained disruption.

## Enforcement

Report conduct concerns privately to the repository maintainers through an available
private GitHub contact channel. Maintainers may edit or remove content and temporarily or
permanently restrict participation when needed to protect the community.

This policy applies in project repositories, discussions, review threads, and other spaces
where someone represents the project.
