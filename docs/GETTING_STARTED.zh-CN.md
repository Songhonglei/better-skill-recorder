# Better Skill Recorder · Preview V0.1.0

把一次真实操作录制下来，整理成可以交给 AI 智能体使用的 Skill

## 下载与安装

- [下载 Preview V0.1.0](https://github.com/Songhonglei/better-skill-recorder/releases/tag/preview-v0.1.0)
- 仅支持 Apple Silicon Mac（M 系列），不提供 Intel Mac、Windows 或 Linux 安装包
- 普通用户不需要 Node、npm 或 GitHub Copilot；这些开发工具不是安装前提
- 这是 **Unsigned Preview**：采用临时签名，未经 Apple Developer ID 签名和公证，尚未完成独立干净 Mac 的全流程验收

1. 下载 Release 中的 ZIP 和 `SHA256SUMS.txt`，不要下载页面自动生成的 Source code 来安装
2. 把两个文件放在同一文件夹，在终端进入该文件夹，执行 `shasum -a 256 -c SHA256SUMS.txt`，确认显示 `OK`
3. 解压，将 **Better Skill Recorder.app** 拖到「应用程序」后打开
4. 如被拦截，仅在确认来源与校验值可信后，进入「系统设置 → 隐私与安全性」，找到该 App 的「仍要打开」并确认

不要关闭系统整体 Gatekeeper，不要执行来源不明的安全绕过命令。受管理的电脑如不允许放行，请联系管理员。参见 [Apple 官方说明](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)

## 第一次使用

### 1 · 授予权限

允许屏幕录制，开启旁白时允许麦克风；浏览器网址采集可能另外请求 Automation 权限。其他权限仅按实际功能需要授权

录屏权限变更后完整退出并重开 App。如升级后授权仍无效，退出 App，在系统设置移除本 App 的旧条目，再添加「应用程序」中的当前 App 并开启权限。不要重置整个钥匙串或其他应用权限

### 2 · 连接自己的模型

「模型管理」中选择预设，或勾选「自定义模型」输入模型 ID，然后填写 BaseURL 和 API 密钥，点击「测试连接」及「保存并启用」

服务需要支持 OpenAI 兼容 Chat Completions、函数调用和多轮工具调用；开启视觉分析时还需支持图片输入。兼容接口不代表所有模型能力都兼容，预设也不是可用性保证

Qwen 的 Token Plan 与普通 API 使用不同地址和相应账户凭据，请按你的服务类型选择。模型调用费用由所配置的服务商收取，不包含在 App 中

API 密钥由 macOS 加密存储。不要把密钥粘贴进 Issue、截图或分享包；配置文件不应手工写入明文密钥。详情见 [模型配置](MODEL_CONFIGURATION.md)

### 3 · 录制、分析、导出

1. 点击录制按钮，或按 **Option + Shift + R** 开始录制
2. 第一次建议录制不含敏感信息的 20–30 秒操作；旁白可选，首次转写可能需要下载本地模型
3. 结束后打开「录制记录」，检查录制内容并开始分析，按需要修正步骤
4. 生成 Skill，分享时选择 share-safe（给其他人用）版本，并人工检查结果

定时 / 触发型 Skill 是文件包，需由支持对应能力的智能体导入和执行，App 不会替你托管定时运行

## 默认设置与数据

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 最短录制时长 | 5 秒 | 短于阈值的录制会丢弃，结束时提示 |
| 音频最大体积 | 100 MB | 超限不读取，提示路径供压缩或切割 |
| 录屏快捷键 | Option + Shift + R | 可修改，保存时检测全局占用和常用快捷键禁用名单 |
| 录制保留天数 | 30 天 | 空闲清理时将过期会话及内部分析结果移入废纸篓，外部导出不受影响 |

上述设置位于「高级设置」，升级会保留已有自定义值。清理在启动和定期检查时按空闲条件进行，并非到期瞬间执行。重要录制请提前导出

本地数据目录为 `~/Library/Application Support/skill-recorder`，请勿把整个目录发给别人

## 安全边界与已知限制

- 录制及脱敏在本机完成；分析、生成、连接测试会访问你配置的模型服务，本地模型首次下载也需要网络
- 开启安全录制会在发送前尝试隐藏敏感信息，但可能漏检或误遮挡，不要录制密码、客户资料等机密内容
- 关闭安全录制可能发送原始内容；关闭视觉分析仅阻止图片发送，不会阻止分析文本发送
- 不录制系统音频；旁白使用麦克风
- 尚未公证，升级可能需要重新授权；没有自动更新
- 大音频解码仍可能产生较高内存占用，不建议盲目把上限调到最大
- 自动测试通过不等于完整硬件、模型兼容性或安全审计
