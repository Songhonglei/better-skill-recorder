# 2026-09-08 录制与发布前代码审查

范围：录制启动/退出、macOS 窗口及网址采集、录制界面、IPC 边界、音频解码
方法：静态代码审查及现有自动测试，不代表完整渗透测试或全部硬件场景验收

## 本次已修复

- 辅助功能重复弹窗：窗口采集 helper 默认执行 Accessibility 检查，完整模式每次新录制重新开启检查。项目已用独立 Apple Events provider 读取浏览器网址，不需要 helper 的 URL 字段。现在 helper 始终带 --no-accessibility-permission；保留屏幕授权相关的窗口标题获取及独立网址链路
- helper 没有超时：子进程卡住会让轮询一直停留在 polling 状态。增加 5 秒超时和 1 MB 输出上限
- 录制浮动条 Discard 缺少中文映射：补为“放弃录制”
- 录制页卡片高度、说明图标和底部两行文案统一

## 四项改造进展（用户确认后已实施）

- 后台处理：增加会话内持久化标记，成功后清除；启动时串行恢复已结束但未完成的任务（含尚未产出 bundle 的旧会话）。失败保留标记，下次启动重试；处理中的会话不能删除或开始分析。退出仍最多等待后台工作 5 秒，不代表转写在退出前一定完成
- IPC：应用桥统一验证已登记窗口、顶层 frame 与本地文档 URL，拒绝子 frame、外部窗口、导航后的页面；阻止意外导航、重定向、弹窗与 webview。后台采集专用通道保留原有 sender 校验。该改造不等于对所有业务参数的完整 schema 审计
- 音频：同一文件句柄先 stat 再有界读取，拒绝空文件、超限文件、目录和读取中增长/截断；解码块必须顺序到达，限制块大小并拒绝重复元数据。大型音频的分段解码仍可作为后续优化
- 快捷键：界面读取实际注册结果；冲突时提示使用录制按钮或解除冲突，并提供重试注册入口
- 自动验证：类型检查和 202 项测试通过，新增有界读取、处理恢复及 IPC 来源与导航约束测试

## 录屏授权根因

本机 tccd 日志明确记录 `Failed to match existing code requirement`：旧 ScreenCapture 授权绑定的证书根与当前 App 签名不同。当前构建与已安装 App 的签名要求一致；签名初始化脚本新增保护，已有签名材料但找不到可用 identity 时停止，避免自动覆盖旧证书

恢复方式：仅移除系统设置中的本 App 旧录屏授权条目，重新添加 `/Applications/Better Skill Recorder.app` 并由用户开启权限、重启。无需重置钥匙串或其他 App 的权限。应用已添加权限设置与重新检测入口；无可用屏幕时禁止静默开始不完整录制。实际授权后录制验收仍需在用户完成系统操作后进行

## 原始审查发现（保留背景）

### P1：退出会在 5 秒后截断后台处理

位置：electron/main.ts 的 before-quit 和 postProcess 回调

录制文件虽然已由 stop() 保存，但 processSession 和本地转写可能超过 5 秒。此时退出会留下未完成的衍生文件，当前没有持久化任务队列保证下次启动自动恢复

建议：持久化处理阶段、支持取消，并在下次启动恢复未完成任务；界面准确标识“待处理”

### P1：IPC 需要统一发送来源检查和页面导航限制

位置：electron/ipc.ts registerIpc；electron/window.ts loadRoute

许多具有文件、录制或配置操作能力的 handler 忽略 event，未统一验证 senderFrame 的来源；窗口也未集中限制导航和新窗口。sandbox 与 contextIsolation 不能代替 IPC 授权

这是一项防御缺口，不是已证实的远程攻击：当前页面加载本地内容，仍需攻击者先找到可利用的页面执行或导航入口

建议：按窗口及 frame 校验允许的本地页面，阻断非预期导航/新窗口，并为各通道增加输入 schema

### P2：音频内存上限在读取之后才检查

位置：electron/audio/decode.ts:17

readFile 先完整载入文件，再检查 512 MB 上限；巨大的文件可能在检查前占用过多内存。IPC、ArrayBuffer 切片和解码还会增加峰值内存

建议：对已打开的文件句柄检查大小并进行有界读取；限制解码长度及通道数，后续评估分段处理

### P2：快捷键注册失败只写日志

位置：electron/main.ts 的 globalShortcut.register

被其他程序占用时用户仍会看到快捷键提示，却没有失败提示或替换入口

建议：向界面返回注册状态，并提供重新注册或自定义快捷键入口
